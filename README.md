# VMS Empire

One continent-spanning war against the computer, with armies, fleets and planes: the 1970s ancestor of Civilization.

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

```
av install vms-empire
av play vms-empire
```

Or download the archive for your system from this repository's Releases,
unpack it and run `./vms-empire` (`vms-empire.exe` on Windows).

## Credits

Walter Bright wrote Empire in the early 1970s; Chuck Simmons wrote this C
version in 1987, and Eric S. Raymond has maintained it since around 1990.
This build is ESR's 1.23 plus a patch so it builds and saves on Windows.
